# Favicon (Issue #5)

## 2026-10-18 21:49 — Start

### Background and motivation

- Issue #5 "Add a favicon". `frontend/public/favicon.svg` is still the default Astro logo.
- The app should have its own icon in the browser tab.
- `main` is already deployed, so this work goes to the `dev` branch only.

### Implementation details and approach

- Draw a simple burger icon as SVG (`viewBox="0 0 64 64"`): top bun, lettuce, patty, bottom bun.
- Keep it to four layers with transparent gaps so it stays readable at 16x16 px.
- Use brand colors from `frontend/src/styles/global.css` (`--color-secondary-container` #ffaa00 for the bun, `--color-tertiary-container` #2e7d32 for the lettuce).
- In the first draft the patty and lettuce disappeared on dark tab bars. Fix this with `@media (prefers-color-scheme: dark)` inside the SVG, as the old Astro favicon did.

### Related files

- `frontend/public/favicon.svg`
- `frontend/src/layouts/layout.astro` (favicon `<link>`)

## 2026-10-18 21:50 — Done

### Actual design intent

- Four flat layers with gaps; seeds are the only detail and simply blur away at 16 px.
- Colors live in CSS classes inside the SVG so the dark-mode override only changes the lettuce (#5cbf60) and the patty (#b25a2e).
- The layout had no favicon `<link>`, so browsers fell back to `/favicon.ico` (still the Astro logo). Added both links:
  - `favicon.ico` (16/32/48 px, generated from the SVG with ImageMagick) for browsers without SVG favicon support
  - `favicon.svg` listed last so browsers that support it prefer it

### Side effects

- `favicon.ico` has no dark-mode variant (ICO cannot use media queries); it always uses the light colors.
- Browsers cache favicons aggressively; a hard reload may be needed to see the change.

### Related files actually modified

- `frontend/public/favicon.svg`
- `frontend/public/favicon.ico`
- `frontend/src/layouts/layout.astro`

### Implementation results

- `npm run build` succeeds; every page's `<head>` contains both icon links.
- Rendered at 16 px on light and dark backgrounds: all four layers are distinguishable.
- Committed to `dev` only; `main` (deployed) is untouched.
